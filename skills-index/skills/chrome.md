Screens
Top: the address bar (type a search or a web address), the tab count square, and the three-dot menu.
Menu: New tab, New Incognito tab, History, Downloads, Bookmarks, Settings.
Tab switcher (the tab count square): every open tab. Swipe one away to close it.

Common tasks
Opening a site: tap the address bar, type the address, then Go on the keyboard.
Closing all tabs: open the tab switcher, then the three-dot menu, then Close all tabs.
Clearing history: menu, History, then Delete browsing data.

Warnings
Wallet sites are copied by scammers with one letter changed. Check the address bar before connecting a wallet.
A site that asks for a seed phrase is a scam, always.
A connect button on a website opens Seed Vault; read the request there before approving it.
Chrome sometimes hides its page from screen reading, so Heylana may not see the page itself.
